# hardware

| Folder | Content |
|---|---|
| `cad/` | 3D-printed lever arm, motor mounts (STEP + STL, with print settings) |
| `wiring/` | E-stop / STO wiring (photos, diagram), power supply setup |
| `electronics/` | Load cell + HX711 + Arduino sketch and its calibration |

Bench supply: output 1 at 24 V (0.15 A limit) to the e-stop / STO; output 2 at 48 V (3 A limit) to motor power.
